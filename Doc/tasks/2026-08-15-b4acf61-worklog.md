# 任务工作记录（Worklog）

> 记录本次会话完成的「逻辑线程 ↔ 渲染线程统一场景同步」重构。
> 当前 HEAD：`b4acf61`（本次改动**未提交**，保留在工作树）

## 概述

本次会话参考 UE 的 `FScene` / `FSceneProxy` / `FSceneRenderer` 模式，把"逻辑线程 → 渲染线程"的
场景数据传输收敛为单通道：`Scene`（注册代理）→ `SceneSnapshot`（值快照）→ `SceneRenderer`（镜像 + GPU 资源），
并落地了渲染线程视锥剔除、光源数据通路、组件生命周期与 ADR-7 延迟删除。

## 阶段 1：剔除数学与池化缓冲

- 新增 `Src/Spark.Engine/Math/BoundingSphere.cs`（中心+半径，CreateFromPoints/Transform/Intersects）
- 新增 `Src/Spark.Engine/Math/Frustum.cs`（6 平面，Gribb-Hartmann 提取，球-视锥相交）
- 新增 `Src/Spark.Engine/Render/FrameBuffer.cs`（池化数组，每帧归零计数复用，IReadOnlyList<T>）

## 阶段 2：场景代理体系与快照

- 新增 `Render/SceneProxy.cs`（`SceneProxy` 基类 + `SceneCategory` + `VisibilityFlags`）
- 新增 `Render/StaticMeshSceneProxy.cs`、`Render/LightSceneProxy.cs`（含 `LightType`）
- 新增 `Render/Scene.cs`（逻辑侧注册表：Register/Unregister/Capture，稳定 `ProxyId`）
- 新增 `Render/SceneSnapshot.cs`（`SceneObjectHeader` + `StaticMeshPayload`/`LightPayload` + `CameraSnapshot`）
- 删除 `Render/FrameData.cs`（`FrameData`/`RenderItem`/`CameraRenderInfo` 被 `SceneSnapshot` 取代）

## 阶段 3：渲染侧渲染器与生命周期

- 新增 `Render/SceneRenderer.cs`：上传处理 → 生命周期 diff → 分组 → acquire → 剔除 → clear → draw →
  present → 延迟删除
- `MeshGPUResource` 拆分为「几何（资产，按 MeshId）」+ `StaticMeshRenderState`（每实例 MVP，按 ProxyId）
- 修复潜在 bug：原每网格共享单 uniform buffer，多实例会互相覆盖；现每实例独立 buffer
- ADR-7 落地：`_pendingDelete` 帧末批量释放，替换原直接删除

## 阶段 4：组件与场景系统改造

- `ActorComponent` 新增 `BeginPlay`/`Update`/`EndPlay`（对应 UE TickComponent），`Actor` 转发
- `StaticMeshComponent`/`LightComponent` 据此注册/同步 `SceneProxy`；`LightComponent` 为新增
- `World` 新增 `Scene` 注册表，移除 `CollectRenderItems`
- `CameraComponent` 新增 `ClearColor`（清屏色不再硬编码）
- `StaticMesh` 新增本地包围球 `Bounds`

## 阶段 5：接入与验证

- `EngineApplication` 改用 `DualFrameBuffer<SceneSnapshot>`，`FillFrameData` 填相机 + `Scene.Capture`
- `RenderThread` 退化为线程外壳，渲染逻辑委托 `SceneRenderer`
- `Demo.Desktop` 增加点光源 Actor
- 构建：`dotnet build Spark.Engine.slnx` **0 错误**（仅遗留 `SceneComponent._attachParent` 未赋值警告）

## 阶段 6：文档更新

- 新增 `Doc/SceneSync-Design.md`（同步机制设计 + ADR-8~ADR-11）

## 阶段 7：场景代理源生成器（SceneGen）

- 新增 `Spark.Engine.SceneGen` 分析器项目（`IIncrementalGenerator`，netstandard2.0）
- 新增 `[SceneProxy]`/`[ScenePayload]` 两个 attribute（`Render/SceneProxyAttributes.cs`）
- `StaticMeshComponent`/`LightComponent` 迁到 attribute 驱动：组件只写 `[ScenePayload]` 字段 +
  默认值 + `OnProxyMapped` 语义钩子
- 删除手写 `StaticMeshSceneProxy.cs`/`LightSceneProxy.cs`（proxy/payload 改为生成）
- `SceneSnapshot` 改 partial：payload 字段 + `ClearPayloads` 由生成器产出；新增 `AddObject<T>` 收口
- `LightType` 枚举迁至 `SceneProxy.cs`
- 构建：`dotnet build Spark.Engine.slnx` 0 警告 0 错误；生成产物经 `EmitCompilerGeneratedFiles` 核验
