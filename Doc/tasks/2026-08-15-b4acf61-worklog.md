# 任务工作记录（Worklog）

> 记录「逻辑线程 ↔ 渲染线程统一场景同步」重构 + SceneGen 源生成器的完整会话。
> 已提交：`73554c7`（分支 v2）

## 概述

参考 UE 的 `FScene` / `FSceneProxy` / `FSceneRenderer` 模式，把"逻辑线程 → 渲染线程"的场景数据传输
收敛为单通道：`Scene`（注册代理）→ `SceneSnapshot`（值快照）→ `SceneRenderer`（镜像 + GPU 资源）。
并落地了渲染线程视锥剔除、光源数据通路、组件生命周期、ADR-7 延迟删除，以及 SceneGen 源生成器
（写 Component 生成 Proxy + 资源成员自动降级/上传）。

## 阶段 1：剔除数学与池化缓冲

- 新增 `Src/Spark.Engine/Math/BoundingSphere.cs`（中心+半径，CreateFromPoints/Transform/Intersects）
- 新增 `Src/Spark.Engine/Math/Frustum.cs`（6 平面，Gribb-Hartmann 提取，球-视锥相交）
- 新增 `Src/Spark.Engine/Render/FrameBuffer.cs`（池化数组，每帧归零计数复用）

## 阶段 2：场景代理体系与快照

- 新增 `Render/SceneProxy.cs`（`SceneProxy` 基类 + `SceneCategory` + `VisibilityFlags` + `LightType`）
- 新增 `Render/Scene.cs`（逻辑侧注册表：Register/Unregister/Capture，稳定 ProxyId）
- 新增 `Render/SceneSnapshot.cs`（`SceneObjectHeader` + `CameraSnapshot` + `AddObject<T>`）
- 删除 `Render/FrameData.cs`（`FrameData`/`RenderItem`/`CameraRenderInfo` 被 `SceneSnapshot` 取代）

## 阶段 3：渲染侧渲染器与生命周期

- 新增 `Render/SceneRenderer.cs`：上传处理 → 生命周期 diff → 分组 → acquire → 剔除 → clear → draw →
  present → 延迟删除
- `MeshGPUResource` 拆分为「几何（资产，按 MeshId）」+ `StaticMeshRenderState`（每实例 MVP，按 ProxyId）
- ADR-7 落地：`_pendingDelete` 帧末批量释放，修复多实例共享单 buffer 的潜在 bug

## 阶段 4：组件与场景系统改造

- `ActorComponent` 新增 `BeginPlay`/`Update`/`EndPlay`（对应 UE TickComponent），`Actor` 转发
- `World` 新增 `Scene` 注册表，移除 `CollectRenderItems`
- `CameraComponent` 新增 `ClearColor`；`StaticMesh` 新增本地包围球 `Bounds`

## 阶段 5：接入与验证

- `EngineApplication` 改用 `DualFrameBuffer<SceneSnapshot>`，`FillFrameData` 填相机 + `Scene.Capture`
- `RenderThread` 退化为线程外壳，渲染逻辑委托 `SceneRenderer`
- 构建：`dotnet build Spark.Engine.slnx` 0 错误

## 阶段 6：文档更新

- 新增 `Doc/SceneSync-Design.md`、更新 `Doc/README.md`、`Doc/RenderPipeline-Design.md`

## 阶段 7：场景代理源生成器（SceneGen）

- 新增 `Spark.Engine.SceneGen` 分析器项目（`IIncrementalGenerator`，netstandard2.0）
- 新增 `[SceneProxy]`/`[ScenePayload]` 两个 attribute（`Render/SceneProxyAttributes.cs`）
- `StaticMeshComponent`/`LightComponent` 迁到 attribute 驱动，删除手写 proxy/payload
- `SceneSnapshot` 改 partial：payload 字段 + `ClearPayloads` 由生成器产出
- 移除 `[SceneProxy]` 的 snapshotField 字符串参数（字段名由类别推导：Mesh→+es，其余→+s）

## 阶段 8：资源成员降级 + 自动上传

  `SyncProxy` 里自动 `EnsureUploaded`
- 新增 `Render/MeshLibrary.cs`（按 MeshId 去重自动上传）；渲染侧 `ProcessUploads` 去重兜底
